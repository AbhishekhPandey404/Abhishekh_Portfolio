## 🚀 About the Project

This portfolio website provides an overview of my professional and technical profile in a clean, responsive, and user-friendly interface.

It is designed to help recruiters, developers, and visitors quickly explore my:

* 👨‍💻 Technical skills
* 🚀 Projects
* 🎓 Education
* 💼 Professional experience
* 📜 Resume
* 📞 Contact information

The repository contains the complete source code for the portfolio website.

## ✨ Features

* 🎨 Clean and modern portfolio design
* 📱 Fully responsive layout
* 💻 Developer-focused profile sections
* 🚀 Project showcase
* 🛠️ Skills and technology section
* 🎓 Education information
* 💼 Experience section

* 📬 Contact section
* ⚡ Interactive navigation

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, animations, and visual design
* **JavaScript** – Interactivity and navigation functionality
* **Responsive CSS / Media Queries** – Mobile and tablet compatibility

The repository contains `index.html`, `style.css`, `mediaqueries.css`, `script.js`, and an `assets` directory.

## 💻 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/AbhishekhPandey404/Abhishekh_Portfolio.git
```

### 2. Navigate to the Project

```bash
cd Abhishekh_Portfolio
```

### 3. Open the Website

Open `index.html` directly in your browser.

For development, you can also open the project in **Visual Studio Code** and use the **Live Server** extension.
